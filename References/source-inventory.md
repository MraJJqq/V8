# 素材来源与整理清单

整理日期：2026-11-07

## 当前正式源码归档

- `V6/`：56 个 V6 源码、页面、样式、资源及验证文件，另含 1 份 `OPERATING-FLOWS.md` 操作流程文档。
- V6 归档源码按对应版本原样复制；本轮清理不改写 `V6/` 下任何文件。
- V6 使用 Gate USDT 永续行情、四个显示周期（1H、4H、8H、1D）及 V12 公共信号数据。
- V6 内部保留 Logo、图标和运行模块本地副本，以满足页面独立运行。

## 顶层长期素材

- `Backgrounds/`：背景 SVG、生成图及生成源代码；背景更新频繁，独立维护。
- `Brand/`：品牌 SVG 与 App 图标。
- `Logos/`：27 个品种 SVG。
- `Cards/`：行情卡片视觉模板。
- `Charts/`：EMA 配色与 K 线视觉规范。
- `References/`：品种映射、V12 数据接口和 Vegas 规则说明。
- `Templates/`：Bark 通知展示模板。
- `UI/`：视觉 Token 与底部信号栏规范。

## 保留与去重原则

- 顶层素材与 V6 本地资源即使 SHA 相同，也分别承担素材主目录和页面本地依赖的用途，均保留。
- 不以文件名相似作为删除依据；仅清理确认不再作为当前源码入口的根目录旧运行模块。
- 背景资源不纳入 V6 源码快照同步；本清单不宣称背景引用已完成运行验收。

## 排除项

- V12 动态 `public-signals.json` 快照不作为固定素材保存。
- 行情请求、信号计算、扫描、推送、状态、缓存运行数据及密钥不作为顶层共享运行模块保存。
- 不在素材库根目录维护第二套 V6 Logo、卡片、周期、K 线、生命周期或信号栏运行实现。
