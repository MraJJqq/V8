# VEGAS V6 — 全屏幕动态系统

## 目标
让 V6 的背景、K线、Logo、周期切换、27 张行情卡片和底部信号栏共同适配实际可用视窗，在手机/平板的不同尺寸及横竖屏之间保持内容可见、文字可读和交互完整。

## 统一规则
- 页面以动态视口高度为准，并提供传统视口回退。
- 横屏与竖屏分别设置模块尺寸范围。
- safe-area inset 在对应模块边界应用一次；K线绘图区保持全屏。
- 尺寸使用 clamp/min/max，避免无限缩小或超出可用空间。
- 背景保持 cover，不改变素材比例或内容。
- Canvas 仍由 K线模块的 ResizeObserver 和 DPR 逻辑管理。
- 周期切换按钮按 iframe 实际高度缩放。
- 卡片小屏减少可见数量，设置卡片尺寸下限，优先可读性；不改卡片点击、拖动、惯性、自动轮播和行情刷新。
- Logo 的原有结构、位置关系、颜色、淡入淡出保持不变。
- 信号栏只调整可用宽度、高度和安全区，不改 V12 数据读取与滚动行为。

## 锁定项
- K线数据源、周期、均线、手势缩放与视窗状态逻辑。
- Logo 切换动画与倒计时逻辑。
- 卡片业务数据、点击/拖动交互、轮播与报价刷新逻辑。
- V12 信号读取、内容和滚动逻辑。
- 背景、Logo、行情图标等素材内容。

## 验收
1. 小屏竖屏：卡片文字可读、周期按钮可点、Logo 不裁切。
2. 大屏竖屏：布局不异常放大，模块不重叠。
3. 横屏短高度：K线保留主要操作空间，周期控件和卡片区不挤占过多高度。
4. 刘海/底部安全区：模块不被系统区域遮挡，inset 不重复叠加。
5. 页面旋转和视窗变化后，Canvas、卡片布局和控件尺寸自动更新。
6. 不改变 K线/卡片/信号/Logo 的业务行为。
