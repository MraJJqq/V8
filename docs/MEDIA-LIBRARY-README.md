# VEGAS Media Library

VEGAS 的长期素材库与系统源码归档。V8 正式网页以本仓库 `V6/` 目录中的六系统源码基线构建。

## 目录结构

- `V6/`：六大系统完整运行源码：K 线、统一视窗与手势、滚动行情卡片、Logo 与倒计时、五周期选择、全屏幕动态适配。统一周期为 1H、2H、4H、8H、D；背景素材单独维护。
- `Backgrounds/`：背景 SVG、生成图像及其源代码，独立维护。
- `Brand/`：VEGAS 品牌标识与应用图标。
- `Logos/`：22 个品种 SVG 标识。V6 运行目录保留本地副本，保证独立运行。
- `Cards/`：行情卡片视觉参考模板。
- `Charts/`：EMA 配色与 K 线视觉规范。
- `References/`：品种映射、信号数据接口、Vegas 规则和素材来源说明。
- `Templates/`：通知展示参考模板，不包含通知运行逻辑。
- `UI/`：页面视觉 Token 与布局规范。

## 源码维护原则

1. `V6/` 是六大系统运行源码的唯一主目录；素材库根目录不维护第二套运行模块。
2. `V6/assets/`、`V6/cards/`、`V6/kline/`、`V6/modules/` 和 `V6/tests/` 是完整运行包的一部分，不得为减少重复而删除。
3. 顶层 `Logos/`、`Brand/`、`Backgrounds/` 等是素材主目录；与 V6 本地副本内容相同不代表可删除。
4. 信号扫描与通知属于独立服务，不属于这六大页面系统；本仓库只保留必要的接口规范和参考模板，不保存扫描器、通知运行状态或密钥。
5. 背景资源独立维护，不作为 V6 运行源码同步的一部分；更新背景时单独核对页面引用和部署产物。
6. 修改六大系统时，先更新 `V6/`，再将该次 Media **提交 SHA** 写入 V8 的 `.media-source-sha`。V8 部署工作流会检出该固定提交并同步运行文件；直接修改 V8 生成的运行副本会在下次同步时被覆盖。
7. `V6` 前缀是内部模块、缓存和存储键的兼容命名空间，不代表当前部署仓库版本。V8 是网页部署版本标识；未经专项迁移，不得批量重命名 V6 标识。

## 当前边界

- 本仓库是六大页面系统及配套素材的源代码库，不承担信号扫描或通知执行。
- 不保存交易所密钥、Bark 密钥或动态行情/信号快照。
- 历史提交可追溯；清理素材时不得误删仍被 V6 运行包引用的本地副本。
