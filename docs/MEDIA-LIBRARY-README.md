# VEGAS Media Library

VEGAS 的长期素材库与系统源码归档。当前正式页面系统以 `V6/` 目录中的完整源码快照为准。

## 目录结构

- `V6/`：V6 页面及七大系统的完整源码归档，包含 K线、视窗、卡片、Logo、周期、信号、全屏幕动态系统；统一周期为 1H、2H、4H、8H、D，背景资源不包含在该快照内。
- `Backgrounds/`：背景 SVG、生成图像及其源代码。背景资源更新频繁，独立维护。
- `Brand/`：VEGAS 品牌标识与应用图标。
- `Logos/`：27 个品种 SVG 标识。V6 同时保留自己的本地副本，保证独立运行。
- `Cards/`：行情卡片视觉参考模板。
- `Charts/`：EMA 配色与 K 线视觉规范。
- `References/`：品种映射、信号接口、Vegas 规则和素材来源说明。
- `Templates/`：Bark 通知展示模板。
- `UI/`：页面视觉 Token 与信号栏视觉规范。

## 源码维护原则

1. V6 的页面运行代码以 `V6/` 为唯一归档位置；不在素材库根目录维护第二套运行模块。
2. V6 本地运行资源保留在 `V6/assets/`、`V6/cards/`、`V6/kline/` 和 `V6/modules/`，不得为减少重复而删除。
3. 顶层 `Logos/`、`Brand/`、`Backgrounds/` 等是素材主目录；与 V6 本地副本内容相同不代表可删除。
4. V12 负责生成正式信号；V6 只读取 V12 公共信号数据并展示，不在本仓库复制信号生成、扫描或推送实现。
5. 背景资源独立维护，不作为 V6 源码同步的一部分。更新背景时单独核对页面引用和部署产物。
6. 修改视觉规范或资源时，核对 V6 实际实现，避免文档与运行代码漂移。

## 当前边界

- V6 是当前页面系统标准；V6 归档快照不应被素材整理操作改写。
- 本仓库不保存交易所密钥、Bark 密钥或动态行情/信号快照。
- 旧版根目录运行模块已清理；历史 Git 提交仍可追溯。
